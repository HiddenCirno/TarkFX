# TarkFX

SPT 4.1 的客户端/服务端插件集合。

## StockMarket — 塔科夫证券交易所

在背包界面顶部新增一个「交易所」Tab，提供一支（未来多支）股票的行情、K 线
与买卖。服务端是唯一权威：价格推进、K 线生成、持仓与资金全部在服务端完成。

完整设计见 [`StockMarket/ARCHITECTURE.md`](StockMarket/ARCHITECTURE.md)。

### 结构

```
StockMarket/
  Client/    netstandard2.1  BepInEx 插件（UI + 轮询）
  Server/    net10.0         SPT 4.1 服务端 mod（路由 + 行情引擎）
```

### 构建

```bash
dotnet build -c Release
```

默认把客户端部署到 `I:\TKF\BepInEx\plugins\TarkFX.StockMarket`，
服务端部署到 `I:\TKF\SPT_Runtime\user\mods\TarkFX.StockMarket`。
换安装目录：`dotnet build -c Release -p:SptRoot=D:\path\to\SPT`。

只编译不部署：`-p:SkipDeploy=true`。

### 运行

服务端首次启动会：

1. 记录行情时钟锚点（2016-01-01 起，7× 塔科夫时间）；
2. 回填 200 根历史 K 线，之后每 15 分钟塔科夫时间（≈128.6 现实秒）推一根；
3. 每根 K 线追加后写 `data/market.json`，持仓写 `data/portfolios.json`。

### 当前口径

- 价格基准：卢布股 10,000 起步、最小报价 1 卢布（涨跌以百卢布计）；美元/欧元股按 100 起步配置
- 冲击曲线：`marketImpactCoefficient × (Q/BaseVolume)^marketImpactExponent`，默认 sqrt（凹曲线）
- 波动率：15 分钟基准 σ 0.6%，安静/活跃两状态切换，跳变约每 200 根一次
- 成交金额：`round(单价 × 股数)`，与原版商店一致（19.19×1→19，19.19×10→192）
- 涨跌幅：相对**昨收**（96 个 tick 为一个塔科夫交易日）
- T+1：24 小时**塔科夫时间**（现实约 3.43 小时）
- 手续费：卖出侧 **0.5%**（`feeRate`，现货卖出 / 平多头 / 开空）；买入、平空、强平、还款不计费
- 分红：现货批次每持满 7 塔科夫日（672 tick，含第一次周期）按 `min(现价−发行价, 发行价×10%) × 持股数` 发系统邮件；现价 ≤ 发行价则当期不分红
- 卖出回款：系统邮件
- 战局内：可看行情，不能买卖；**服务端同样强制拦截**（`RaidStateTracker`）
- 交易冲击：买卖会推动价格（`config.json` 的 `marketImpactCoefficient`，0 = 关闭）
- 杠杆：**1–100 倍**（输入框 + 快捷 1/5/10/20）；1x 多头 = 现货；保证金亏完自动强平，强平同样产生冲击
- 做空：向券行借股（券源 = 总股本 30%）→ 卖出款冻结 → 权益 ≤ 0 强平（买回）；**卖出款不直接给玩家**
- 分批平仓：空头 / 杠杆多都可以按数量平，剩余仓位保留；强平仍为整仓
- 平仓文案：「平仓可得（含保证金）」+ 专用结算邮件，避免把退还的本金误看成利润
- 持股上限：**100,000 股/股/人**（现货 + 杠杆多 + 空头合计，毛持仓口径）
- 多空：同一股票**允许同时持多与空**（对冲）；同方向仍限一笔杠杆多、一笔空头
- 欠债：强平/主动平仓出现负权益时记欠债，多空都记；欠债未清零前封锁全部股市操作、冻结持仓
- 还款：独立输入框 + 按钮，走 item 队列扣现金，支持部分偿还
- 券池：平仓/强平/转生归还券源
- 熔断：首次触及涨跌停后，该股票强平暂停 **96 tick（24 塔科夫小时）**；期间可主动平仓
- 转生：清空债务/现货/杠杆/空头，归还券源，无冲击、无邮件
- 强平复盘：`data/liquidation.log`（UTC/塔科夫时间、tick、方向、触发价、成交均价、结算、欠债）
- 余额同步：买入/开多/开空/还款全部走原版 `client/game/profile/items/moving` 队列，仓库 UI 与服务器一致
- 分批成交：买卖每 10 股重算一次价格（可配），大额交易有滑点，无法全部成交在第一口价
- 盈亏展示：只显示**账面**（按现价浮盈浮亏）与**变现**（按同一冲击曲线立刻平仓的净额，卖出含手续费）；不显示已实现/总盈亏
- 预计分红：单列一行，按现价与现货持股估算下一周期分红；欠债冻结期间为 0
- Debug 模式：`config.json` 的 `debugMode=true` 时 T+1 归零（当前测试配置已开启）
- 涨跌停：单日相对昨收 **±30%**（`dailyLimitPercent`），价格与冲击都被夹在区间内

### 图表

- Y 轴价格刻度 + 底部时间刻度
- 现价虚线 + 昨收参考虚线 + 蓝色持仓成本线
- MA5 / MA20
- 默认显示最近 120 根（配置项 `1. 图表 → 可视 K 线根数`），图表上可用鼠标滚轮缩放
- Y 轴放宽系数默认 1.35（上下各留约 15%），嫌波动太陡就调大
- 红涨绿跌 / 绿涨红跌可切换（配置项 `1. 图表 → 红涨绿跌`）
- 数量控件：−1000 / −100 / −10 / −1 / 输入框 / +1 / +10 / +100 / +1000
- 方向：做多 / 做空；杠杆：1/5/10/20 快捷 + 输入框（1–100）
